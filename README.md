# ATK 电量

ATK / VXE / VGN 2.4G 鼠标的电量托盘工具。单文件，不需要安装，不联网，不写日志。

## 下载

从 [Releases](https://github.com/GyroZeppel1/atk-battery/releases) 取 `atk-tray.exe`，放到任意目录双击即可。仓库里只有源码，构建产物不进版本库。

也可以自己编译，见文末。

## 用法

双击桌面上的「ATK 电量」（或 `atk-tray.exe`），弹出面板：

```
┌────────────────────────────────┐
│  ATK X1 Air +                  │
│                                │
│  60%                  3.98 V   │
│                       放电中    │
│  ██████████████░░░░░░░░░░░     │
│  更新于 17:12:03 · 2.4G        │
└────────────────────────────────┘
```

托盘图标是一个**环形电量表**：填充的弧长就是电量，不用看数字也能一眼判断。

| 颜色 | 含义 |
|---|---|
| 绿 | ≥ 60% |
| 琥珀 | 30–59% |
| 红 | < 30% |
| 蓝 | 充电中 |
| 灰环 + 中心点 | 暂时读不到（鼠标休眠） |

鼠标悬停在图标上会显示型号和精确百分比。

## 托盘操作

左键点图标：显示 / 隐藏面板

右键点图标：菜单

```
打开面板
立即刷新
──────────────────
✓ 开机自启
✓ 启动时打开面板
──────────────────
创建桌面快捷方式
──────────────────
退出
```

- **开机自启**：在启动文件夹创建快捷方式，任务管理器 →「启动」里能看到、能禁用
- **启动时打开面板**：取消勾选后，双击只会在托盘运行，不弹窗
- **退出**：关闭面板只是收进托盘，真正退出要用这一项

> **找不到托盘图标？** Windows 11 默认把新图标折叠进任务栏的 `^` 面板。点开 `^`，把电量图标拖到任务栏上就能常驻。

## 刷新时机

- 正常每 60 秒读一次
- 读不到时每 5 秒重试，所以鼠标休眠唤醒后几秒内就会自动恢复
- 想手动刷新：右键「立即刷新」，或直接左键点一下图标

## 支持范围

按设备暴露的 HID 报告结构自动识别，不看型号名：

| 协议 | 典型设备 |
|---|---|
| Compx 17 字节 | ATK F1 Ultimate、A9 Ultimate、X1 Air +、VXE MAD R、VGN F1 Pro 等 |
| Nordic 64 字节 | ATK Zero（含 8K 接收器） |

已实测：`373B:1278` = **ATK X1 Air +**，无线，读数与官方 ATK HUB 一致。

未登记的型号同样能读，只是名字显示成 `ATK family XXXX:YYYY`。

## 设置

```
%LOCALAPPDATA%\ATK Battery\settings.ini
```

```ini
show_panel=1   # 1 = 手动启动时打开面板，0 = 只进托盘
```

删掉这个文件即恢复默认。

## 构建

需要 Rust（GNU 或 MSVC 目标均可）。仓库已带 `.cargo/config.toml`，GNU 目标走 `rust-lld` 自包含链接，不需要 Visual Studio。

```bash
cargo build --release    # 产出 atk-tray.exe
```

Windows 一键：`.\build.ps1`

## 原理

每次查询只发一条固定的只读请求，校验回复后取电量：

- **17 字节**：`08 04 00 … 49`，17 字节求和 mod 256 须为 `0x55`，电量在 byte 6，电压 byte 8–9（大端）
- **64 字节**：`08 7D 72 02 00 <link> 07 01 …`，byte 2 状态位 0 表示鼠标本人应答，电量在 byte 7

实现细节、踩过的坑和性能数据见 [`docs/技术方案.md`](docs/技术方案.md)。
